# 📚 小说播放器 v2.1

一款现代化的 Windows 桌面小说朗读软件。支持导入 TXT 小说、多引擎 AI 语音朗读、逐句高亮跟读、书签管理、9 色阅读背景、可拖拽进度条。

---

## ✨ 功能

### 核心朗读
- 🎙️ **双引擎语音** — 微软 Edge TTS 在线 AI 语音（12 种发音人）+ SAPI 本地离线语音，自动回退
- 🔊 **阅读界面语音设置** — 朗读中随时切换语音、调整语速/音量，一键试听，保存为默认
- 📖 **逐句高亮跟读** — 音频回调精确驱动，不估时不乱跳
- ⚡ **异步预生成管道** — 播放当前批次时后台生成下一批，无缝衔接零间隙

### 阅读体验
- 🎨 **9 色阅读背景** — 米白/纯白/暖黄/浅绿/浅蓝/浅粉/浅灰/深灰/纯黑，一键切换自动保存
- 📊 **可拖拽进度条** — Canvas 手绘，点击/拖拽跳转到任意位置，显示剩余朗读时间
- ▶️ **圆形播放按钮** — 播放/暂停双态图标，视觉醒目
- 📑 **目录搜索** — 输入关键字快速定位章节

### 书架 & 进度
- 📥 **智能导入** — 自动检测文件编码，识别中英文章节标题
- 📌 **阅读进度** — 自动记忆上次阅读位置，精确到句子
- 🔖 **书签管理** — 添加备注/一键跳转/删除

### 主题 & 快捷键
- 🌙 **暗色模式** — 亮色/暗色双主题
- ⌨️ **全快捷键** — Space 播放/暂停、← → 句间跳转、Ctrl+B 书签、Ctrl+I 导入、Esc 返回

## 🚀 安装

```bash
# 1. 克隆仓库
git clone https://github.com/loyalzhh/novel-player.git
cd novel-player

# 2. 安装依赖
pip install -r requirements.txt
```

---

## 🎮 使用

```bash
python main.py
```

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放 / 暂停 |
| `→` `←` | 下一句 / 上一句 |
| `⏭` `⏮` | 下一章 / 上一章 |
| `Ctrl + B` | 添加书签 |
| `Ctrl + I` | 导入小说 |
| `Esc` | 返回书架 |

---

## 📦 依赖

| 包 | 用途 |
|----|------|
| `edge-tts` | 微软 Edge TTS 在线 AI 语音，12 种发音人（含粤语/台语/方言） |
| `pyttsx3` | Windows SAPI 本地离线语音引擎 |
| `chardet` | 文本文件编码自动检测 |

## 📁 项目结构

```
novel-player/
├── main.py                # 主程序入口（侧边栏 + 视图切换）
├── db_manager.py          # SQLite 数据库（小说/章节/进度/书签/语音方案/设置）
├── tts_engine.py          # TTS 引擎（Edge + SAPI，异步生成，自动回退）
├── chapter_parser.py      # 章节自动识别 + 智能分句
├── utils/
│   └── theme.py           # 亮/暗双主题 + 9 色阅读背景预设
├── views/
│   ├── library_view.py    # 书架视图（卡片列表/搜索/导入）
│   ├── reader_view.py     # 阅读器（高亮/进度条/语音弹窗/背景色/预生成）
│   └── settings_view.py   # 设置视图（语音方案/外观）
└── requirements.txt
```
